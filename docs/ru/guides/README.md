# Arona

**Платформа для самостоятельного развёртывания и удалённого управления моделями ИИ.**

Arona — это **чисто серверная** платформа, написанная на Rust (axum): она одновременно
является OpenAI-совместимым шлюзом моделей *и* управляющей плоскостью для моделей, которые
вы запускаете на собственном оборудовании. Она обслуживает OpenAI-совместимый REST API
`/v1/*`, управляющую плоскость JSON-RPC 2.0 (`/api/rpc`), плоскость управления агентами
(`/ws/agent`) и Swagger UI на `/docs`.

Здесь **нет встроенной веб-панели и встроенного CLI-чата** — чат и admin UI живут в
[shittim-chest](https://github.com/celestia-island/shittim-chest), который общается с Arona
через RPC-поверхность. Arona сосредоточена на серверной стороне: маршрутизация, billing,
auth, развёртывание моделей, агенты и память.

## Матрица возможностей

| Область | Что предоставляет Arona |
| --- | --- |
| **Ядро диалогов** | OpenAI-совместимые `chat.completions` (stream и non-stream), `embeddings`, список `models`; стриминг с терминальным чанком `[DONE]` и реальным usage в финальном чанке. |
| **Backends** | Зарегистрированные администратором upstream-сервисы: `external` (любой OpenAI-совместимый HTTP API), `ollama`, CEP `engine` (WebSocket), `minimax-cloud` для видео и bridge-URL `evernight://` для промышленных/edge-сервисов. |
| **Аутентификация** | Пары JWT access/refresh (15 мин / 7 дней), API keys `arona-{uuid}`, хранящиеся в виде SHA-256-хешей, три уровня администратора, политика паролей, двухтрековое ограничение частоты запросов. |
| **Billing и usage** | Предустановленные tiers (free / pro / enterprise), записи usage для каждого запроса на каждом канале, таблица цен plana, квотирование по проектам, 429 + `Retry-After`. |
| **Управление моделями** | Скачивание моделей (источники `hf:` / `ms:` / `gh:`), развёртывание на GPU-узлах `_agent`, автоматическая регистрация развёрнутых моделей как маршрутизируемых backends. |
| **Realtime и мультимодальность** | Полнодуплексные сессии `realtime.*`, канал восприятия/управления `engine.invoke`, асинхронные задачи генерации видео (MiniMax cloud). |
| **Кластер агентов** | GPU-узлы подключаются через `/ws/agent`, размещение по наименьшей загрузке, привязка сессий, сохранение узлов между перезапусками. |
| **Memory gateway** | Долговременная память через entelecheia Philia: инъекция воспоминаний, запись эпизодов, явная деградация. |
| **Операции** | Health-пробы, трассировка `RUST_LOG`, отображение ошибок upstream (502 против 500), graceful shutdown, автоматическая миграция при старте. |

## Позиционирование

Arona — это **шлюз + платформа**: она маршрутизирует трафик моделей на ваши backends,
развёртывает модели на ваших GPU-агентах и учитывает всё.

- по сравнению с **pi** — pi это CLI-ассистент, который общается с моделями; у arona нет
  CLI-чата. Arona — это платформа, *с которой* общается pi (и другие инструменты).
- по сравнению с **one-api / new-api** — это шлюзы API keys перед providers моделей;
  arona добавляет **развёртывание моделей** (скачивание весов, запуск их на ваших агентах),
  полноценную управляющую RPC-плоскость, billing tiers и память.
- по сравнению с **LiteLLM** — это шлюз-аналог; arona дополнительно владеет жизненным
  циклом развёртывания моделей, стоящих за шлюзом.

## Структура репозитория

```
packages/
├── core/    # Core logic: gateway, routing, billing, auth, memory, RPC
├── agent/   # Remote agent (bin `_agent`): deployed on GPU machines
└── cli/     # CLI (bin `_cli`): install, deploy, serve, migrate, download
```

Веб-панель была удалена из этого репозитория и теперь живёт в
[shittim-chest](https://github.com/celestia-island/shittim-chest) (chest #291).
