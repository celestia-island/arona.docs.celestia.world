# arona.docs.celestia.world

Published documentation of **[Arona](https://github.com/celestia-island/arona)**
(self-deployment and remote management platform for AI models).

This repository is an **automatically synced mirror**: everything under `docs/`
and the `README.md` are pushed here by the
[`docs.yml` workflow](https://github.com/celestia-island/arona/blob/master/.github/workflows/docs.yml)
in the private source repository whenever documentation changes. **Do not edit
files here** — changes will be overwritten by the next sync. Contribute to the
`arona` repository instead.

The site is built with [lagrange](https://github.com/celestia-island/lagrange)
and served at **<https://arona.docs.celestia.world>** (11 languages:
en / zh-Hans / zh-Hant / ja / ko / fr / es / ru / ar / de / pt).
